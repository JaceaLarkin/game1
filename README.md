# Little Dungeon

A small turn-based roguelike that runs in your browser.

## Run it in VS Code

1. Open this folder in VS Code.
2. Open `index.html` in a browser, or install the **Live Server** extension and choose **Go Live**.
3. Move with WASD or arrow keys. Fight goblins, collect gold and potions, and step on `>` to descend.

Every move gives nearby goblins a turn. When your health reaches zero, select **New run** to start over.
